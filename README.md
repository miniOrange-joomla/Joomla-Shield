# JoomShield – Joomla Web Security Extension

JoomShield by miniOrange is a Joomla security extension that helps protect Joomla websites from unauthorized access, brute-force login attempts, suspicious traffic, and fake user registrations.

It provides security controls for administrator access, user registration, IP filtering, password policies, and website activity monitoring, helping Joomla administrators manage and strengthen their website security.

## Key Features

- **Admin Login Protection:** Customize the administrator login URL with a secret access key to make it harder for bots to discover.
- **Brute-Force Protection:** Track failed login attempts and block offending IP addresses to help prevent password-guessing attacks.
- **Strong Password Enforcement:** Apply password strength requirements to improve account security.
- **Fake Registration Prevention:** Block registrations from specified disposable or unwanted email domains.
- **IP Address Filtering:** Allow or block specific IP addresses and supported IP ranges.
- **Web Firewall:** Filter traffic using supported criteria, such as IP address, country, or browser.
- **Login Activity Reports:** Review login attempts and identify suspicious access patterns.
- **Email Notifications:** Receive security alerts and user notifications where supported.
- **Additional Security Tools:** Access features such as temporary administrator accounts, emergency lockdown, and database maintenance.

## Installation

### Option 1: Install from the Joomla Extensions Directory

1. Log in to your Joomla administrator dashboard.
2. Navigate to **System → Install → Extensions**.
3. Upload the JoomShield installation package or use the available extension installation options.
4. Complete the installation.
5. Open **Components → miniOrange - JoomShield** to access the extension settings.

Visit the [Joomla Extensions Directory](https://extensions.joomla.org/extension/joomshield-by-miniorange/) to find the extension.

### Option 2: Install from GitHub

1. Open the [Joomla-Shield GitHub repository](https://github.com/miniOrange-joomla/Joomla-Shield).
2. Navigate to the `Release` directory, if available, and locate the installation package.
3. Download the Joomla extension installation package.
4. Log in to your Joomla administrator dashboard.
5. Navigate to **System → Install → Extensions**.
6. Upload the downloaded package and complete the installation.
7. Open **Components → miniOrange - JoomShield** to configure the extension.

**Important:** Install the Joomla extension package rather than uploading the repository source files directly. Follow the package-specific installation instructions if they differ from these steps.
